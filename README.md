# Sprint_5 — автотесты для Stellar Burgers

Автотесты учебного сервиса Stellar Burgers (Selenium + pytest).

## Что проверяется
- Регистрация (успешная и с некорректным паролем)
- Вход 4 способами: с главной, через «Личный кабинет», из формы регистрации, из формы восстановления пароля
- Переходы в «Личный кабинет» и обратно в «Конструктор» (кнопка и логотип)
- Выход из аккаунта
- Переключение разделов конструктора: «Булки», «Соусы», «Начинки»

## Запуск
pytest -v
